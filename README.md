 DropVault

DropVault is a Chrome Extension built to streamline tab management during research-heavy workflows. Whether you're comparing products, collecting resources, exploring supplier websites, or simply managing large numbers of browser tabs, DropVault provides a quick and organized way to save, access, and manage important links directly from the browser.

The project was developed using Vanilla JavaScript, Chrome Extension APIs, and Local Storage, with a focus on simplicity, speed, and usability, it also increased the traffic for their website 

how to download and run.
No compilation is required. You can test it directly as an unpacked Chrome extension:

Clone or download this repository.
Open chrome://extensions in Chrome.
Enable Developer mode.
Click Load unpacked.
Select the DropVault1 folder (the folder containing manifest.json).
The extension should then appear in your extensions list — pin it and you're good to go!
